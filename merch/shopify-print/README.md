## Upload to Shopify (Printful / Gelato / similar)

1. Create a Shopify store (or connect an existing one). Suggested public URL later: `shop.englishstudy.club` (DNS CNAME → Shopify).
2. In your print partner (Printful, Gelato, etc.), create products: tote, mug, notebook, sticker.
3. Upload each SVG as the print file / design layer. Keep the cream/navy backgrounds; do not replace the logo with a new crest.
4. Publish products and copy the collection URL.
5. Replace the placeholder link on `/tienda/` (`https://shop.englishstudy.club`) with the real Shopify URL.

## Brand locks

- Logo source of truth: existing PNG logos only.
- Colors: cream `#f7f4ef`, navy `#102849`, burgundy `#8f1731`, gold `#d4a63a`.
- Do not invent new wordmarks or heraldic crests.
